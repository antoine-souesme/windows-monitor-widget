# Microsoft Store description

Text of the Store listing, in both languages. Keep it in line with the
features whenever one is added or changed. The screenshots and the
presentation image live in `packaging/store/`.

## Français

```
Monitor Widget affiche l'état de votre PC en direct, dans une petite fenêtre sans bordure posée sur votre bureau. Chaque valeur s'affiche en grand, avec un graphique des 60 dernières secondes, et sa couleur passe du vert au rouge quand la charge monte : vous voyez tout de suite quand votre PC peine.

Vous choisissez ce qui s'affiche : la charge du processeur, la charge de la carte graphique et sa température, la mémoire utilisée (en pourcentage, en valeur ou les deux), le débit du réseau en réception et en envoi, et les images par seconde du jeu en plein écran.

Trois modes d'affichage sont proposés. Le mode normal empile de grands blocs. Le mode compact donne à chaque valeur deux fines lignes : son graphique, puis une jauge. Le mode personnalisé vous laisse composer votre propre grille, en plaçant chaque valeur où vous voulez ; une case peut s'étendre sur deux colonnes.

Déplacez le widget en le faisant glisser, élargissez-le en tirant sur son bord gauche ou droit. Un clic droit ouvre le menu : les options et la fermeture. Dans les options, chaque réglage s'applique tout de suite : métriques affichées, mode d'affichage, langue (français ou anglais), toujours au premier plan, animations fluides, icône dans la zone de notification. Cette icône permet de retrouver le widget s'il a disparu de l'écran.

Le widget se lance avec Windows ; vous pouvez désactiver ce lancement dans les paramètres de Windows (Applications, puis Démarrage). Vos réglages sont conservés d'une mise à jour à l'autre.

À propos des FPS : Windows ne donne les images par seconde des jeux qu'aux comptes du groupe « Utilisateurs du journal de performances ». Un bouton dans les options ajoute votre compte à ce groupe ; il suffit ensuite de fermer votre session Windows puis de la rouvrir. En attendant, le widget affiche les images par seconde du bureau.
```

## English

```
Monitor Widget shows how your PC is doing, live, in a small borderless window sitting on your desktop. Each value is written in large type above a graph of the last 60 seconds, and its color goes from green to red as the load rises: you see at once when your PC is struggling.

You choose what is shown: processor load, graphics card load and temperature, memory in use (as a percentage, as a value or both), network download and upload rates, and the frame rate of the full screen game.

Three display modes are available. Normal mode stacks large blocks. Compact mode gives each value two thin lines: its graph, then a gauge. Custom mode lets you build your own grid, putting each value where you want it; a cell can span two columns.

Drag the widget to move it, pull its left or right edge to widen it. A right click opens the menu: options and quit. In the options, every setting applies at once: displayed metrics, display mode, language (English or French), always on top, smooth animations, icon in the notification area. That icon brings the widget back when it is lost off screen.

The widget starts with Windows; you can turn that off in the Windows settings (Apps, then Startup). Your settings are kept from one update to the next.

About FPS: Windows only gives the frame rate of games to the accounts of the "Performance Log Users" group. A button in the options adds your account to that group; then simply sign out of Windows and back in. Until then, the widget shows the frame rate of the desktop.
```
